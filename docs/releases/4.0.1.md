# AnyKeep 4.0.1

This is the first stable package release following the 4.0.0 release
candidates. It incorporates the editor, synchronization and media fixes that
have been validated in the main development branch since 4.0.0_rc2.

## Highlights

- **Media and attachments:** use bundled vector Play/Pause icons instead of
  font-dependent symbols; show a visible placeholder for remote videos that
  have no thumbnail; generate compact encrypted thumbnails and a locally
  stored video poster; improve audio/video player lifetime and media menus.
- **Image previews:** restore image rendering after the experimental media
  card refactoring, while keeping media selection and editing functional.
- **KDE Wayland:** improve the persistence and restoration of individual note
  window positions, including reloading the KWin geometry script reliably.
- **Editor:** improve navigation between structured blocks and handling of
  multiline lists/tables; refine table-header wrapping and inline code font
  presentation.
- **Packaging:** make Gradle downloads on GitHub Android builders more
  resilient by using a direct distribution URL, longer timeouts, retries and
  caching.

## Compatibility and testing

This release retains the 4.x encrypted-note and media-storage architecture.
As with any cross-device note client, **back up important notes before
upgrading every device**. Allow the initial synchronization to finish before
testing offline behavior.

Test note-window restoration on KDE Wayland, image insertion and display,
video placeholders/posters and playback, audio playback, note editing and
undo/redo, and cross-device XMPP synchronization. Fullscreen playback and
Android multimedia behavior can vary with the installed codecs.

The complete release is published only after the Windows, macOS, Linux and
Android packaging jobs complete successfully. Release assets and checksums
are attached to this GitHub release.
