AnyKeep 4.0.0 — Release Candidate 2

This prerelease replaces 4.0.0_rc1 for testing before the stable 4.0 release.
It fixes editor performance with large tables and the note scrollbar on Linux.
Please report regressions with your operating system, storage provider and
reproduction steps.

### Changes since 4.0.0_rc1

- Notes with large tables open about five times faster. The date picker is
  now created only while it is open instead of once per table cell.
- Selecting text across table cells is smooth again; previously every mouse
  move re-sorted all cell editors.
- Spell checking covers only the focused text, unless a whole-note check is
  requested, and no longer rehighlights the whole note for every table cell.
- Table column widths are measured once from all cells before the table is
  laid out, so tables no longer reflow while opening.
- The note scrollbar is thin and drawn the same way under every Qt Quick
  style. Under KDE it was drawn over a native Breeze scrollbar, with a stray
  line in the middle and two competing fade animations.
- Debian release archives no longer include debug-symbol packages.

### Testing this candidate

Please check notes with tables (opening, selecting, editing column content),
spell checking, scrolling long notes on Linux desktops, and the items from
the 4.0.0_rc1 notes: editing and undo/redo, synchronization between two
devices, offline/reconnect behavior, attachments, and closing the
application with notes open.

Native package metadata uses the numeric version `4.0.0`; the application
identifies this candidate as `4.0.0_rc2`. Windows MSI supports replacement by
the final 4.0.0 installer. This candidate does not update the stable or nightly
auto-update feeds.
