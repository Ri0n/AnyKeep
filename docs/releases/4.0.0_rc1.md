AnyKeep 4.0.0 — Release Candidate 1

This prerelease is intended for testing before the stable 4.0 release.
Please report regressions with your operating system, storage provider and
reproduction steps.

### Highlights

- Shared structured editor across desktop and Android, with formatting,
  lists, tables, code, attachments and media.
- Folders, favorites, archive and recycle-bin organization.
- Encrypted local drafts, recovery and offline storage caches.
- Updated XMPP synchronization and encryption support.
- Desktop integrations for Plasma, GNOME, Cinnamon, Windows and macOS.
- Scrollable tray note lists; optional body search in the fallback tray.
- Windows installers and self-update infrastructure.
- Improved dark-theme scrollbar contrast and clean standalone-window shutdown.

### Testing this candidate

Please check editing and undo/redo, synchronization between two devices,
offline/reconnect behavior, attachments, and closing the application with notes open.

Native package metadata uses the numeric version `4.0.0`; the application
identifies this candidate as `4.0.0_rc1`. Windows MSI supports replacement by
the final 4.0.0 installer. This candidate does not update the stable or nightly
auto-update feeds.
